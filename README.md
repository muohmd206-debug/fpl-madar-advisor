# مَدار — FPL Advisor

مستشار عربي لفانتزي الدوري الإنجليزي، جاهز على **Windows وAndroid**.

[تنزيل Windows مباشرةً](https://github.com/muohmd206-debug/fpl-madar-advisor/releases/latest/download/Madar-Windows-x64.zip) · [آخر إصدار](https://github.com/muohmd206-debug/fpl-madar-advisor/releases/latest)

## Windows: تنزيل وتشغيل دون تثبيت أدوات

1. نزّل **Madar-Windows-x64.zip** من الرابط أعلاه أو من قسم **Releases**. هذا هو الملف المحمول الجاهز؛ ملفات **Source code** هي ملفات التطوير.
2. اضغط بزر الفأرة الأيمن على الملف واختر **استخراج الكل / Extract All**.
3. افتح مجلد **Madar** ثم انقر مرتين على **START-MADAR.cmd**.

يفتح التطبيق تلقائيًا في متصفحك على `http://127.0.0.1:8765`. اترك نافذة التشغيل مفتوحة أثناء الاستخدام. للإيقاف أغلق النافذة أو اضغط `Ctrl+C` فيها.

تحتوي النسخة المحمولة على محرك Node.js الرسمي وترخيصه؛ **لا تحتاج إلى تثبيت Node.js أو npm أو أي حزم**. المتطلبات: Windows 10/11 بمعالج x64 ومتصفح حديث. إذا كان المنفذ مستخدمًا يختار التطبيق منفذًا محليًا قريبًا ويعرض الرابط. تُحفظ التشكيلة في المتصفح على عنوان التطبيق المحلي؛ حافظ على نفس المتصفح والمنفذ، أو صدّر الخطة قبل النقل.

## Android: تثبيت من Chrome

1. افتح نسخة الويب من مَدار في **Chrome** وانتظر اكتمال التحميل الأول.
2. اضغط رمز التنزيل في أعلى التطبيق، أو انتقل إلى **الإعدادات ← تثبيت على جهازي**.
3. إذا لم يظهر طلب التثبيت، افتح قائمة Chrome **⋮** واختر **تثبيت التطبيق / Install app** أو **إضافة إلى الشاشة الرئيسية**.

يظهر التطبيق بأيقونة مستقلة ويفتح في نافذته الخاصة. هذه نسخة ويب قابلة للتثبيت، ولا تحتاج إلى ملف APK أو متجر تطبيقات. يمكن تثبيتها أيضًا من Chrome أو Edge على Windows.

## العمل دون إنترنت

- النسخة المحمولة تتضمن نسخة رسمية محفوظة مؤرخة من بيانات FPL.
- النسخة المثبتة من المتصفح تحفظ ملفات التطبيق ونسخة البيانات بعد اكتمال أول تحميل متصل، وتستخدم آخر تحديث محفوظ عند الانقطاع.
- يظهر بوضوح أن البيانات محفوظة مع تاريخها؛ أسعار اللاعبين والإصابات لا تبقى محدثة دون اتصال.
- التحديث المباشر واستيراد Team ID يتطلبان الإنترنت. تبقى التشكيلة والإعدادات محفوظة في المتصفح، ويمكن تصديرها من الإعدادات.
- بيانات النسخة المحلية ونسخة الويب منفصلة؛ انقلها بواسطة تنزيل الخطة ورفعها، وليست هناك مزامنة حسابات تلقائية.

## الوظائف

- بناء مسودة من 15 لاعبًا بميزانية افتراضية £100m، وقيود المراكز وثلاثة لاعبين لكل نادٍ.
- مقارنة xG وxA وxGI وxGC والدقائق والبونص والتصديات والملكية العامة والمباريات.
- اختيار الأساسيين والكابتن والنائب، واقتراح نقلات فردية قابلة للتمويل.
- حساب سعر البيع وفق سعر الشراء الفعلي، وعرض إشارات صافي نقلات الجولة.
- تخطيط الرقاقات حسب نوافذ الموسم والمباريات المجدولة.
- استيراد آخر تشكيلة عامة عبر Team ID، وحفظ الخطة محليًا وتصديرها.

يستخدم مَدار قواعد ونموذجًا حسابيًا لحساب التوصيات. لا يسجل الدخول إلى FPL ولا ينفذ نقلات. البيانات من API الرسمي؛ احتمالات الشباك النظيفة والنقاط تقديرات موضحة في صفحة المنهجية. ملكية النخبة وتدفقات آخر 24 ساعة غير متاحة من المصدر المتصل. صافي نقلات الجولة لا يضمن موعدًا لتغيير السعر.

## تشغيل ملفات المصدر

للمطورين الذين نزّلوا ملفات المصدر: Node.js 22 أو أحدث، دون تثبيت حزم:

```sh
npm start
```

يبني المشغل التطبيق تلقائيًا عند غياب ناتج البناء، ثم يفتح المتصفح. خيارات التشغيل:

```sh
node start.mjs --no-open
node start.mjs --offline --port=8765
npm test
```

يعمل الخادم على `127.0.0.1` فقط. ناتج `npm run build` هو `dist/server/index.js`، ويمكن نشره كـ Cloudflare Worker. يضم الملفات الثابتة ونسخة البيانات المؤرخة، ويمكن تحديث ملفات `data/` من API الرسمي وإعادة البناء.

لإنتاج ZIP Windows، جهّز مجلدًا يحتوي على `node.exe` و`LICENSE` و`VERIFIED.json` بعد التحقق من SHA-256 لتوزيعة Windows الرسمية من nodejs.org، ثم شغّل:

```sh
npm run build
node scripts/package-windows.mjs --runtime-dir=/absolute/path/to/verified-runtime
```

يُنتج الحزم في `releases/` ويضيف بصمة SHA-256 وبيانات مصدر المحرك وترخيصه. هذه الملفات لا تُضمّن في Git.
