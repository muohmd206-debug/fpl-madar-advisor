# مَدار — FPL Advisor

تطبيق عربي مستقل لتحليل فانتزي الدوري الإنجليزي، أُعد للبداية من الجولة 11 في موسم 2026/27.

- يبني مسودة من 15 لاعبًا بميزانية افتراضية £100m وقيود المراكز وثلاثة لاعبين لكل نادٍ.
- يقارن xG وxA وxGI وxGC، الدقائق والبونص والتصديات والملكية العامة والمباريات.
- يختار الأساسيين والكابتن والنائب، ويقترح نقلات منفردة قابلة للتمويل.
- يحسب سعر البيع وفق سعر الشراء الحقيقي، ويعرض إشارات صافي نقلات الجولة.
- يخطط للرقاقات وفق نوافذ الموسم والمباريات المجدولة.
- يستورد آخر تشكيلة عامة عبر Team ID، ويحفظ التشكيلة محليًا ويصدر خطة JSON.

يستخدم مَدار قواعد ونموذجًا حسابيًا لحساب التوصيات. لا يسجل الدخول إلى FPL ولا ينفذ نقلات. البيانات من API الرسمي؛ احتمالات الشباك النظيفة والنقاط من نموذج تقديري موضح في صفحة المنهجية. ملكية النخبة وتدفقات آخر 24 ساعة ليست متاحة من المصدر المتصل. لا يُفسَّر صافي نقلات الجولة كتوقع مضمون للأسعار.

## التطوير

لا يحتاج المشروع إلى تثبيت حزم. Node.js 20 أو أحدث:

```sh
npm run build
npm test
```

الناتج `dist/server/index.js` هو Cloudflare Worker بوظيفة `fetch`. يضم الملفات الثابتة ونسخة رسمية محفوظة مؤرخة لحالة انقطاع المصدر. يمكن تحديث ملفات `data/` من API الرسمي وإعادة البناء.

التطبيق يجلب بيانات اللاعبين والجدول مباشرةً مع تخزين مؤقت لمدة 3 دقائق، ويحدث سجلات الفريق والمرشحين في المتصفح بعد 3 ساعات وسجل اللاعب عند فتحه. يُحفظ سجل التحديث في المتصفح. يبيّن التطبيق تاريخ النسخة الاحتياطية وحدود بياناته.

## التحقق

تغطي الاختبارات قيود الفريق، التشكيلة القانونية، مضاعفة الكابتن، أرباح البيع، قانونية النقلات وتكلفة الخصم، الغياب، الجولات المزدوجة والشاغرة، نوافذ الرقاقات، استجابات Worker، النسخة الاحتياطية المؤرخة، ورندر جميع صفحات التطبيق مع سياق DOM مصغر. هذا لا يعادل فحص العرض في متصفح حقيقي.
